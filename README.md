# 金券・デジタルギフトイベント調査

Amazonギフトカード、QUOカードPay、えらべるPay、giftee、Visaギフト、PayPay等がもらえるイベント・ウェビナー・アンケート等を整理する台帳です。

## Web台帳

無料食事イベント台帳 `01-event` に近い、横並び4列の表形式です。

`日付（または期間）｜イベント名｜特典 / 条件｜備考`

- イベント名の2行目に媒体名を表示
- 特典 / 条件は、オンライン・オフライン、特典額、全員・先着・抽選、必要条件だけを簡潔に表示
- REPLAY、要再確認、未受領などは備考欄に表示
- 会社メール条件、SMS認証、付与時期など細かい情報は「詳細」に格納

## 主なファイル

- `案件一覧.json`：現在受付中、過去案件、未受領ギフト、対象外・低優先などの実データ
- `引き継ぎ.md`：ChatGPT等のAI向け説明書・調査ルール・表示仕様
- `index.html`：Webページの表示用
- `README.md`：この案内板

## 普段の更新

**通常の案件追加・修正は `案件一覧.json` だけを更新します。**

表示方法やデザインを変更するときだけ `index.html` を変更します。
